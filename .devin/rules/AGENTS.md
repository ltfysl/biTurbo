## .devin/rules

Agent-specific instruction files for Devin.

## Rules

- Keep rules declarative and concise.
- One rule file per project/agent context.
- Do not duplicate instructions from root `AGENTS.md` or `INSTRUCTIONS.md`.
- Update when project conventions change.

## Best practices

- Put reusable, cross-cutting rules in a single file such as `biturbo.md`.
- Keep trigger frontmatter stable.
