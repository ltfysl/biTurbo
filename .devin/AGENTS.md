## .devin

Devin agent configuration directory.

## Rules

- Keep configuration declarative; no implementation code here.
- One rule/prompt per concern.
- Do not duplicate instructions already covered by root `AGENTS.md` or `INSTRUCTIONS.md`.
- Keep files small and focused.

## Best practices

- Put reusable agent rules under `.devin/rules/`.
- Keep the folder versioned with the rest of the repo.
